# v2 release preparation

The `v1.0.0` tag is preserved as the archived CHH-focused version of this project.

The current `main` branch is being prepared for the expanded TE-distant gene-network manuscript. The manuscript file itself is deliberately excluded from the repository.

Before creating the `v2.0.0` GitHub release, verify that:
- all exact scripts used for the manuscript are present;
- compact processed result tables required to reproduce reported values and figures are present;
- no raw FASTQ/BAM/full WGBS archives are committed;
- `Supplementary_Table_S2.xlsx` is current;
- software versions and random seeds are documented where recoverable;
- `.zenodo.json` and `CITATION.cff` match the final manuscript title and authorship.
